# NOVA IMS Teaching Staff Analysis

## 📌 Overview  
Built a web scraping pipeline to collect data from the NOVA IMS teaching staff directory and analyzed faculty profiles to uncover patterns in publications, course loads, and biographies. Presented findings and built a regression model to benchmark faculty performance.  
**Grade: 19.8/20**

## 🛠️ Features  
- **Web Scraping:** Automated faculty data extraction using Selenium and BeautifulSoup  
- **Data Cleaning:** Handled missing values and deduplicated entries  
- **Analysis:**  
  - Publication prediction using Gradient Boosting Regression  
  - NLP on biographies and word cloud generation  
  - Association rule mining for course recommendations  
- **Visualization:** Interactive dashboards using Plotly  

## 📁 Dataset  
**Source:** NOVA IMS website  
**Structure:**  
- `Name`  
- `Title`  
- `Courses`  
- `Publications`  
- `Biography`

- Gained insights into academic performance and faculty profiling
